# CPU：Ricoh 2A03（6502 内核）

> 对应源码：`AtomNES.Device/Cpu/Cpu6502.cs`、`OpcodeTable.cs`、`Disassembler.cs`，总线调度见 `AtomNES.Device/Bus/NesBus.cs`。

## 1. 概览

| 项目 | NTSC 值 |
|------|---------|
| 主时钟 | 21.477272 MHz |
| CPU 时钟 | 主时钟 ÷ 12 ≈ 1.789773 MHz |
| 每帧 CPU 周期 | ≈ 29780.5 |
| 寄存器 | A、X、Y、SP（8 位）、PC（16 位）、P（状态） |

2A03 是去掉了十进制模式（BCD）的 MOS 6502，并在同一芯片内集成了 APU 与 DMA 控制器。`D` 标志仍可置位，但 `ADC`/`SBC` 不会按 BCD 计算。

## 2. 状态寄存器 P

```text
 7 6 5 4 3 2 1 0
 N V - B D I Z C
```

- `B`（bit4）和 bit5 在寄存器里并不存在，只有在压栈时才出现：`PHP`/`BRK` 压入 `B=1`，IRQ/NMI 压入 `B=0`，bit5 总是 1。
- `I` 只屏蔽 IRQ，不屏蔽 NMI。

## 3. 内存映射

```text
$0000-$07FF  2KB 内部 RAM（$0800-$1FFF 为镜像）
$2000-$2007  PPU 寄存器（$2008-$3FFF 每 8 字节镜像）
$4000-$4017  APU 与 I/O（$4014 OAM DMA，$4016/$4017 手柄）
$4018-$401F  CPU 测试模式（正常不使用）
$4020-$FFFF  卡带空间（PRG ROM / PRG RAM / Mapper 寄存器）
$FFFA/$FFFC/$FFFE  NMI / RESET / IRQ-BRK 向量
```

没有设备响应的地址返回**开放总线**（上一次总线上的值）。

## 4. 周期精确的关键：每个周期一次总线访问

6502 的每个时钟周期**一定**发生一次总线读或写，包括很多"看起来没用"的访问：

- **索引跨页的哑读**：`LDA $12FF,X`（X=1）会先读 `$1200`（未修正的高字节），再读 `$1300`。写指令和读改写（RMW）指令无论是否跨页都会做这次哑读。
- **RMW 双写**：`INC/DEC/ASL/LSR/ROL/ROR` 会先把旧值写回一次，再写新值。MMC1 等 Mapper 依赖这个行为（连续周期的第二次写被忽略）。
- **隐含寻址与栈操作的空读**：`PHA`、`RTS`、`TAX` 等指令也会读 PC 或栈地址。

模拟器只有把这些访问都做出来，读 `$2002`、`$2007`、`$4015` 这类**读会产生副作用**的寄存器时才会和真机一致。本项目里 `Cpu6502` 每次调用 `bus.Read/Write` 就是一个 CPU 周期，总线在访问前后推进 PPU/APU。

### 主时钟相位

`NesBus` 用主时钟建模：一个 CPU 周期 = 12 个主时钟，一个 PPU 点 = 4 个主时钟。读访问发生在周期的第 5 个主时钟，写访问发生在第 7 个主时钟。PPU 在访问之前追赶到对应的主时钟，因此 `$2002` 读与 VBlank 置位的竞争可以精确到单个 PPU 点。

## 5. 中断

| 中断 | 触发方式 | 说明 |
|------|----------|------|
| RESET | 上电/复位 | 7 周期，3 次压栈被抑制为读，SP 减 3，置 I |
| NMI | **边沿**触发 | 来自 PPU（VBlank），不受 I 屏蔽 |
| IRQ | **电平**触发 | 来自 APU 帧计数器、DMC、Mapper；受 I 屏蔽 |
| BRK | 软件 | 与 IRQ 共用向量，压入 B=1 |

### 轮询时机

CPU 在**指令最后一个周期之前**（倒数第二个周期）采样中断线。由此自然产生这些真机行为：

- `CLI`/`SEI`/`PLP` 改变 I 后，新值要到下一条指令结束时才生效（延迟一条指令）。
- 发生跳转的分支指令如果没有跨页，不会在第 3 个周期轮询，会延迟中断。
- **中断劫持**：BRK 或 IRQ 正在压栈时如果来了 NMI，会改用 NMI 向量，但仍压入原来的 B 标志。

## 6. DMA

### OAM DMA（`$4014`）

写 `$4014` 后 CPU 在下一个**读周期**被挂起：1 个停顿周期 +（当前为奇数周期时）1 个对齐周期 + 256 次"读 → 写 `$2004`"，共 513 或 514 周期。

### DMC DMA

APU 的 DMC 通道需要取样本字节时，同样在 CPU 读周期挂起 CPU：停顿 + 哑读 +（需要时）对齐，共 3~4 周期，然后执行一次真实读取。哑读会重复上一次的读地址，因此可能对 `$2007`、`$4016` 产生额外副作用（真机 bug，已模拟）。

## 7. 非官方指令

NES 游戏会用到部分非官方指令（`LAX`、`SAX`、`DCP`、`ISC`、`SLO`、`RLA`、`SRE`、`RRA`、多字节 `NOP` 等）。本项目实现了全部 256 个操作码，其中 `JAM/KIL` 会让 CPU 停机（`Jammed = true`），只能复位恢复。测试里"CPU 停机"通常意味着 Mapper 映射错误导致跑到了数据区。
