# Mapper 现状与开发计划

> 对应源码：`AtomNES.Device/Cartridges/`。工厂入口 `MapperFactory`（`SimpleMappers.cs`）。

## 1. 什么是 Mapper

NES 的 CPU 只能直接寻址 32KB PRG（`$8000-$FFFF`），PPU 只能直接寻址 8KB CHR（`$0000-$1FFF`）。卡带上的 Mapper 芯片负责：

- **分页（bank switching）**：把更大的 ROM 按 8/16/32KB（PRG）或 1/2/4/8KB（CHR）切换到这些窗口。
- **名称表镜像控制**：水平/垂直/单屏/四屏。
- **附加功能**：扫描线或 CPU 周期 IRQ、PRG RAM（含电池存档）、扩展音频、CHR RAM 等。

本项目的 `Mapper` 基类用页表实现：PRG 4 个 8KB 槽、CHR 8 个 1KB 槽、名称表 4 个 1KB 槽，热路径只查一次数组。派生类只需要在寄存器写入时更新页表。

## 3. 本地 ROM 库覆盖情况

`D:\资源\rom` 共 252 个 ROM，已支持 80 个 Mapper。未支持的只剩 19（2 个）与 85（1 个），均需扩展音频。

## 4. 实现难度分级

| 难度 | 特征 | 例子 |
|------|------|------|
| ⭐ | 只有分页 + 镜像，几十行 | 离散逻辑板、多合一、248 |
| ⭐⭐ | 分页 + IRQ 计数器（CPU 周期或 A12），复用现有 `VrcIrq`/MMC3 逻辑 | 64、91、117、18、16、67、73、75、195 系列 |
| ⭐⭐⭐ | 需要新的硬件机制 | 68（ROM 名称表）、163/164（保护 + 特殊读）、176（大型多模式 MMC3） |
| ⭐⭐⭐⭐ | **扩展音频** 或复杂 PPU 交互 | 19 (N163 8 声道波表)、24/26 (VRC6 3 声道)、85 (VRC7 FM 合成)、69 的 5B 音频、5 (MMC5) |

**扩展音频**是 19/85/24/26/5 难的根本原因：需要在 APU 混音中加入新的声源，VRC7 甚至要实现 YM2413 的 FM 合成；MMC5 还有扩展属性、分屏、8x16 精灵独立 CHR 等 PPU 交互，是公认最复杂的 Mapper。不过**没有音频的情况下，这些 Mapper 的游戏大多也能先玩起来**，可以先做映射、后补音频。

## 5. 建议开发计划

### 阶段 A：收尾简单项（✅ 已完成）

目标：本地 ROM 库 100%（除 19/85 外）可运行。

1. **248** → 映射到 115。
2. **64** Tengen RAMBO-1：MMC3 变体，多 2 个 CHR 寄存器 + 可选 CPU 周期 IRQ 模式。
3. **91** JY 简化版：MMC3 IRQ + 2KB CHR / 8KB PRG。
4. **117** Future Media：8KB PRG / 1KB CHR + A12 IRQ。
5. 验证：Holy Mapperel 无对应 ROM，采用本地 ROM 抽样 + Mesen 对比。

### 阶段 B：补齐正式发行的中频 Mapper（⭐⭐，约 2 天）

1. **16 / 153 / 159** Bandai FCG（含 EEPROM 存档可后补）。
2. **18** Jaleco SS88006。
3. **67 / 68** Sunsoft-3 / Sunsoft-4（68 需要 CHR ROM 作为名称表）。
4. **73 / 75** VRC3 / VRC1。
5. **24 / 26** VRC6 先做映射与 IRQ（复用 `VrcIrq`），音频放到阶段 D。

### 阶段 C：中文卡带专项（⭐⭐~⭐⭐⭐，约 3 天）

国内玩家最常见的中文 RPG 大多在这里。

1. **195 / 192 / 194 / 199** Waixing MMC3 + CHR RAM（复用 `Mapper74` 的 CHR RAM 机制）。
2. **163 / 164 / 162** 南晶（需要实现保护寄存器读取与 CHR RAM 自动切换）。
3. **176** FK23C。
4. **90 / 209 / 211** JY Company 完整版（91 的超集）。
5. **253** Waixing。

### 阶段 D：扩展音频 + MMC5（⭐⭐⭐⭐，约 1~2 周）

先在 APU 中抽象"扩展音源"接口（输出电平送入同一个 `BandLimitedSynth`），再逐个实现：

1. **VRC6 音频**（2 脉冲 + 锯齿，最简单，先打通框架）。
2. **Sunsoft 5B**（AY-3-8910 兼容，3 方波 + 噪声 + 包络）。
3. **Namco 163**（8 声道波表 + 映射/IRQ）→ 解决本地 19 号的 2 个 ROM。
4. **MMC5**（扩展 RAM、分屏、扩展属性、乘法器、2 脉冲 + PCM）。
5. **VRC7**（YM2413 FM 合成，可参考 emu2413 / Mesen 的实现）→ 解决本地 85 号的 1 个 ROM。

### 并行项

- **电池存档**：✅ 已实现，`HasBattery` 的卡带把 PRG RAM 保存到 ROM 同目录的 `.sav`。
- **NES 2.0 子 Mapper**：VRC2/4、78、BF909x 等已使用 SubMapper，后续新 Mapper 继续按 NES 2.0 规范处理。
- **测试**：每个阶段结束运行 `mmc3_test_2` 与 Holy Mapperel 回归，再做本地 ROM 抽样（每 Mapper 2 个 × 20 秒），失败清单交由用户用 Mesen 确认。
