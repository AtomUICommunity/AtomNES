# APU：2A03 音频处理单元

> 对应源码：`AtomNES.Device/Audio/`（`Apu2A03.cs`、`ApuChannels.cs`、`DmcChannel.cs`、`BandLimitedSynth.cs`），输出见 `AtomNES/Services/AudioOutput.cs`。

## 1. 概览

APU 集成在 CPU 芯片里，与 CPU 同频（≈1.789773 MHz）。它有 5 个声道：

| 声道 | 寄存器 | 波形 |
|------|--------|------|
| 脉冲 1 | `$4000-$4003` | 方波，4 种占空比，带扫频 |
| 脉冲 2 | `$4004-$4007` | 同上（扫频取反方式略有不同） |
| 三角波 | `$4008-$400B` | 32 级阶梯三角波，无音量控制 |
| 噪声 | `$400C-$400F` | 15 位 LFSR，两种模式 |
| DMC | `$4010-$4013` | 1 位增量调制采样，经 DMA 从 PRG 取数据 |

`$4015` 是声道使能/状态寄存器，`$4017` 是帧计数器控制。

## 2. 基本部件

### 定时器（Timer）
每个声道都有一个分频计数器，减到 0 时重载并推进波形一步。脉冲/噪声/DMC 每 2 个 CPU 周期计数一次，三角波每个 CPU 周期计数一次（所以三角波低一个八度）。

### 长度计数器（Length Counter）
写 `$4003/$4007/$400B/$400F` 时从 32 项查找表装入长度；帧计数器的"半帧"信号让它递减，到 0 时声道静音。可以通过 halt 位暂停。

> 细节：在半帧时钟的同一周期写入长度，写入会被忽略或生效取决于当时计数器是否为 0；halt 位的修改要延迟一个周期生效。本项目用"延迟提交"复现了这个行为。

### 包络（Envelope）
"四分之一帧"信号驱动。可以输出固定音量，也可以从 15 线性递减（可循环）。

### 扫频（Sweep，仅脉冲）
"半帧"信号驱动，按 `周期 ± (周期 >> shift)` 调整频率。目标周期 > `$7FF` 或当前周期 < 8 时静音（即使扫频没开启也会判断）。脉冲 1 的减法用反码（多减 1），脉冲 2 用补码。

### 线性计数器（三角波专用）
"四分之一帧"驱动，比长度计数器更精细的时长控制。三角波周期 < 2 时实际是超声波，常见做法是保持当前输出不变以避免爆音。

## 3. 帧计数器（`$4017`）

| 模式 | 步进（CPU 周期） | 作用 |
|------|------------------|------|
| 4 步 | 7457、14913、22371、29829(+30) | 每步四分之一帧；第 2、4 步半帧；第 4 步可产生 IRQ |
| 5 步 | 7457、14913、22371、29829、37281(+82) | 无 IRQ，频率略低 |

- 写 `$4017` 后，新模式在 3 或 4 个 CPU 周期后生效（取决于写入时是奇数还是偶数周期）。
- 写入时如果选择 5 步模式，会立刻产生一次四分之一帧 + 半帧时钟。
- 复位时重新写入上一次的 `$4017` 值。

## 4. DMC

- 输出一个 7 位计数器（0-127），每个比特让它 +2 或 -2。
- 样本缓冲为空时向 CPU 发起 DMA 读取下一个字节（见 [CPU.md](CPU.md) 的 DMC DMA 一节），地址从 `$C000` 起，超过 `$FFFF` 回绕到 `$8000`。
- 样本播放结束可以循环或产生 IRQ。
- 写 `$4011` 直接设置输出电平，很多游戏用它播放 PCM 人声/鼓声。

## 5. 混音

真机的混音是**非线性**的电阻网络，本项目使用 nesdev 公式：

$$
\text{pulse} = \frac{95.88}{\dfrac{8128}{p_1 + p_2} + 100}
$$

$$
\text{tnd} = \frac{159.79}{\dfrac{1}{\dfrac{t}{8227} + \dfrac{n}{12241} + \dfrac{d}{22638}} + 100}
$$

输出 = pulse + tnd，范围约 0 ~ 1。两个分式都可以预先做成查找表。

## 6. 从 1.79 MHz 到 48 kHz：为什么会有噪音

最朴素的做法是每隔 ≈37.3 个 CPU 周期取一次当前电平。这样做的问题是：方波的边沿含有远高于 24 kHz 的谐波，直接抽样会**混叠**成刺耳的金属噪声和嗡嗡声。旧项目音质差主要就是这个原因。

本项目使用 **带限合成（Band-Limited Synthesis，blip_buf 思路）**：

1. 只在输出电平**变化**时记录一次"阶跃"（时间戳 = CPU 周期，幅度 = 差值）。
2. 每个阶跃不是硬边沿，而是叠加一段预先计算好的**带限阶跃**（加窗 sinc 积分）。本项目使用 64 个相位 × 16 个抽头，按阶跃在两个输出样本之间的小数位置选择相位。
3. 对差分缓冲积分得到最终波形。

再加上真机的模拟滤波链：

| 滤波器 | 截止频率 | 作用 |
|--------|----------|------|
| 一阶高通 | 90 Hz | 去直流 |
| 一阶高通 | 440 Hz | 真机输出电容 |
| 一阶低通 | 14 kHz | 真机输出 RC |

## 7. 音频输出与同步

- 使用 SDL3 的音频流（`SDL_OpenAudioDeviceStream`），16 位单声道 48 kHz，Windows/Linux/macOS 通用。
- 模拟器按帧运行，60.0988 fps 与显示器刷新率、声卡时钟都不会完全一致。`AudioOutput` 以队列水位为目标（约 50ms），用 ±0.5% 的**动态速率控制**微调重采样比，既不爆音也不累积延迟。
- 积压过多时直接清空，非 1x 速度运行时丢弃音频。
